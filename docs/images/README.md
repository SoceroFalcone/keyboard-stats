## 每日概览绘制要求

> Create an original 16:10 native Windows app schematic for Keyboard Stats. Use a light grey-blue sidebar and background, white surfaces, muted blue accents and crisp readable Chinese text. Display the prominent label “界面示意 · 虚构数据”. Show four fictional totals of 8,000, 6,000, 2,000 and 120, a generic unbranded keyboard and upright mouse, a frosted hover card labelled “空格 / 500 次 / 示意数据”, a 24-hour grid and fictional key ranking. Use generic hardware and entirely invented activity. Omit calendar dates, personal identifiers and product brands.

## 历史活动绘制要求

> Create an original matching Windows app schematic for the history screen. Display the prominent label “界面示意 · 虚构数据”. Show device tabs and period choices for 7 days, 30 days, 180 days and one year. Use exactly seven weekday rows in a weekly-column blue heatmap, with the latest week on the right. The summary labels are “区间总次数 / 有记录天数 / 最长连续天数”, with fictional values 80,000, 100 and 7. Include a frosted card labelled “示意日期 / 1,000 次 / 较前一天 +100 次” and table rows “示例 A / 示例 B / 示例 C” with values 1,000, 900 and 800. Omit exact dates and personal identifiers.
