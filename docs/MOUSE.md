# 鼠标统计

## 1.5 键鼠并排

鼠标现在竖直放在照片式无数字区键盘右边，取代原界面数字小键盘的位置。沿用 1.4.1 已验证的素材与五个表面，对图片和点击区域一起旋转约 30.76°：头朝上，两个侧键仍在物理左侧，侧键 2 在前、侧键 1 在后。下方一行保留五键完整次数、选中反馈和占比。

图片解码宽度由 1024 降到 640 像素，以适应更小的并排显示；旋转只使用冻结的界面变换，不保留额外旋转图片。鼠标和新键盘共用按热度等级缓存当前材质的机制，两种模型的像素数据共 6.31 MiB，全部 95 个图片来源在面板退役后均可回收。详见 [测试记录](TESTING.md)。

## 1.4.1 左右方向修正

按用户指定的 [Razer Viper V4 Pro 官方页面](https://www.razer.com/tw-zh/gaming-mice/razer-viper-v4-pro)重新制作模型，参考其对称细长外壳、分体主键、滚轮槽和左侧两枚拇指键。前端朝画面左上，掌托朝右下；左键与两个侧键在同一物理左侧，侧键 2 靠前、侧键 1 靠后。图片是用于热力图的无标识示意，并非硬件识别结果。

1.4 的图片把侧键放到了物理右侧，原先的“左前方”描述有误。1.4.1 更换素材和五块表面轮廓，原有 MouseLeft / MouseRight / MouseX1 / MouseX2 计数含义保持不变。独立图像定位点、前后方向、真实控件点击判定，以及仅左键 / 仅右键数据画面均已验证。旧图片与来源记录归档在 `artifacts/mouse-realistic/source`，不再打包。

保留按热度深浅着色、材质光影、准确次数与悬停 / 选中 / 焦点反馈。新素材和当前贴图保留 4,339,222 字节（约 4.14 MiB）像素数据；窗口退回后台释放后，底图和五块贴图全部可被回收。这里仅指图片像素数据，不等于应用整体内存。

## 1.4 写实鼠标热力图（方向已由 1.4.1 修正）

用一张带透明背景的写实鼠标素材取代 1.3 的轮廓示意图。五个独立表面按统计热度着色，同时使用素材原有亮度保留磨砂质感、曲面高光和滚轮沟槽。文字与准确次数移到旁边，悬停可指示对应部位，点击模型或数字行可查看占比。此版图片的物理左右关系后来由用户指出错误，以上 1.4.1 记录为准。

图片只解码到 1024 像素宽，曲面遮罩仅创建一次；只有热度等级跨级时才生成新的小块表面贴图，计数增加但热度级别不变时复用贴图。每个部位只保留当前等级，没有无界的多版本图片缓存；不增加后台线程、定时器、动画或 3D 渲染循环。素材通过流加载，不进入 WPF 的 URI 图片缓存，所有图片和缓冲均归当前窗口所有。

2026-11-15：WPF 检查通过五个真实点击区域、完整次数、五级材质、明暗纹理保留、贴图冻结/复用、空数据、纯中键数据、百万级数据、焦点/选择、1280 × 900 和 1060 × 700 布局，以及既有日期/历史/后台保存行为。独立生命周期测试确认窗口关闭后模型控件可被回收；可见时素材及贴图保留约 4.91 MiB 像素数据。完整运行内存及对照测量见 [性能记录](PERFORMANCE.md)。

## 1.3 历史实现

鼠标面板改为可交互的俯视与左侧示意图。左键、右键、中键及两个侧键按各自次数使用原有五级绿色色阶，外壳维持中性色。点击部位会显示准确次数和鼠标点击占比；悬停显示完整次数。模型内的大数值按万/亿缩写，详情保留完整数字。

五个区域仍是原生 WPF Button，点击判定使用各自的曲线边界，不会把外壳或空白矩形角落算作按键。支持原生焦点、Tab 与按钮激活；颜色、悬停边框、选中轮廓和焦点轮廓分别呈现。几何与画刷冻结复用，仅数据变化时更新；没有新增渲染循环、动画、定时器、监听线程或 3D 引擎。关闭窗口后的释放与后台采集机制保持不变。

2026-11-15：Release 构建零警告、零错误；真实 WPF 控件检查通过五个部位的曲线内外点击范围、准确选择、独立热度、空数据、仅中键数据、百万级数字、两种窗口尺寸、五级色阶悬停/按下文字对比度，以及隐藏后保存和恢复选择。截图为明确标注的隔离演示数据，位于 `artifacts/mouse-model/preview`；本次仅改变展示，下面的 1.2 采集与存储机制继续适用。

## 1.2 计数规则

新增 Windows 标准五键：左键、右键、中键（滚轮按下）、侧键 1 / 2。每次按下计一次，松开不计；双击计两次，长按和拖拽不重复计数。滚轮滚动、移动与未知按钮消息不计入点击。键盘连发偏好只影响键盘。

## 数据与展示

沿用 schema 1，在每日 Keys 汇总中增加 MouseLeft、MouseRight、MouseMiddle、MouseX1、MouseX2 标识。旧键盘计数无需转换；旧记录没有鼠标项时按已记录的 0 次显示，不补造历史点击。

每日总量、小时总量和全年格子合并两类输入；概览与历史表额外列出键盘/鼠标各自总量。活跃分钟取并集，同一分钟不会因两类输入重复累加。键盘图的颜色与排行占比仅由键盘次数计算，鼠标面板使用独立色阶与占比。CSV 继续使用原列结构，新增鼠标行的本地化名称与「鼠标按键」分类。

## 监听与资源

InputMonitor 在原有消息泵线程上同时安装 WH_KEYBOARD_LL 和 WH_MOUSE_LL。高频移动与滚轮消息在解析原生结构之前直接传递，不进行锁定、日期计算或持久化。按钮回调只更新内存聚合，始终继续传递事件；任何持久化都在原有保存路径完成。复用暂停、锁屏/恢复时的按住状态清理、每 5 秒保存和托盘释放 UI 机制。只新增五个可复用鼠标控件，没有新增轮询定时器或监听线程。

鼠标事件字段及侧键高位字的处理依据 Microsoft [LowLevelMouseProc](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelmouseproc) 与 [MSLLHOOKSTRUCT](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-msllhookstruct)。标准接口区分两个 XBUTTON 侧键；更多厂商自定义键取决于驱动映射，不承诺识别为额外独立鼠标按钮。

## 验证

2026-11-15 Release 构建零警告、零错误，21 项行为测试通过。其中鼠标检查覆盖五键、双击、长按、暂停、注入过滤、移动/滚轮过滤、午夜分日、重置、旧文件兼容、历史汇总与 CSV、原生数据包解码。Windows 集成检查验证两个系统钩子安装成功并正常拆除，以及原有 F24 键盘事件和注入过滤。

鼠标数据包测试在测试进程内部传入原生结构，**没有向用户桌面注入点击**，不把它表述为真实硬件点击测试。界面测试使用隔离演示数据，验证五个按钮、准确总数/占比、键盘色阶不受鼠标影响、纯鼠标日期、历史分项、隐藏后继续收集保存以及窗口恢复选择状态。图片在 `artifacts/mouse/preview` 与 `.impeccable/review/v1.2`，包括两种窗口尺寸及键盘焦点、零数据、纯鼠标状态。

独立界面复核要求修正鼠标方格悬停/按下时的整体透明度。鼠标控件现使用独立模板，以边框显示反馈，保持文字和填充不透明。渲染测试直接驱动实际 WPF 模板的只读状态属性，验证五级色阶及反馈边框；最低文字对比度为 4.94:1。最终复核对该项给出 resolved / ship，不把它扩展为真实硬件或全部显示缩放下的验证。
