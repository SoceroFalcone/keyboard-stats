界面对照使用实际 WPF 控件与相同的 1280 × 900 窗口，预热 10 次后各测量 200 次不变数据刷新和 200 次新增键盘 A + 鼠标右键的刷新。用时包含布局和 Dispatcher 调度，不是帧率；分配量是 UI 线程累计分配，不是常驻内存。

| 可见窗口指标 | 1.3 | 1.4 |
| --- | ---: | ---: |
| 200 次不变数据刷新 | 89.23 ms | 8.19 ms |
| 200 次键鼠计数刷新 | 1,001.89 ms | 511.49 ms |

| 进程工作集样本 | 145.43 MiB | 158.48 MiB |

写实模型在窗口打开时有明确成本：这次进程私有内存样本增加约 12 MiB；素材底图、表面原始像素、遮罩和当前等级贴图合计保留 5,144,578 字节，约 4.91 MiB，另有 WPF 解码/绘制等开销。底图限制为 1024 像素宽，每个按键只保留当前贴图；只有热度跨级才重新着色，没有旋转动画、持续渲染、额外线程或无界贴图缓存。单次受控刷新测试未发现变慢，不作为所有硬件上的速度提升承诺。

## 1.1 历史记录

测量日期：2026-11-14，Windows x64 / .NET 10。比较保留的 1.0 发布版与最终 1.1.0 热力图版本。使用隔离演示数据，不改动真实统计。

## 后台内存

两版使用相同的 14 天预生成数据，冷启动到托盘，等待 4 秒后每隔 2 秒取样，共 5 次。没有预先打开统计窗口。测量脚本为 `scripts/measure-background.ps1`。

| 指标 | 1.0 | 1.1 | 变化 |
| --- | ---: | ---: | ---: |
| 平均进程私有内存 | 49.12 MiB | 17.51 MiB | 降低 64.4% |
| 平均进程工作集 | 104.37 MiB | 73.99 MiB | 降低 29.1% |
| 约 10 秒内 CPU 时间 | 31.25 ms | 15.625 ms | 仅作空闲采样参考 |

私有内存与工作集是不同指标：后者还包含驻留的共享运行库页面。任务管理器显示值会受列选择、窗口是否打开、运行时间和系统状态影响。CPU 数值受 Windows 计时分辨率影响，不能外推为长期利用率。

原始样本：`artifacts/performance/before/background.json`、`artifacts/performance/after-final/background.json`。

## 界面刷新

实际 WPF 控件、相同 14 天数据和 1280 × 900 窗口；预热 10 次，然后分别执行 200 次空闲刷新、200 次新计数刷新，并完成布局和 Dispatcher 空闲调度。分配量统计当前 UI 线程累计分配，**不是常驻内存或 GC 后堆大小**。用时包含该批刷新和布局，**不是帧率**。

| 200 次刷新 | 1.0 | 1.1 |
| --- | ---: | ---: |
| 数据不变：总耗时 | 2,842.66 ms | 9.02 ms |
| 数据不变：UI 线程分配 | 238.71 MiB | 0.25 MiB |
| 每次新增按键：总耗时 | 2,345.87 ms | 403.68 ms |
| 每次新增按键：UI 线程分配 | 241.74 MiB | 10.44 MiB |

有新数据时，这批刷新总耗时减少约 82.8%。单次受控测试说明实现差异，不构成所有硬件上的速度保证。

原始结果：`artifacts/performance/before/refresh.json`、`artifacts/performance/after-final/refresh.json`。测量入口：`KeyTrail.Preview.exe <输出目录> --benchmark`。

## 实际改动

- 托盘启动延迟创建 WPF 面板；关闭到托盘 8 秒后释放面板，保留所选日期、页面、搜索与窗口大小，重新打开时恢复。
- 隐藏和最小化时停止界面刷新定时器。独立键盘监听与 5 秒保存继续工作，不降低计数频率。
- 根据数据版本跳过不必要的刷新；键盘键帽、24 个小时格、排行榜和搜索结果复用控件，共享冻结的画刷。
- 全年活动图一次绘制，不为 365 / 366 个日期构建独立控件；提供鼠标日期命中和键盘日期导航。
- 完整日数据缓存默认最多 32 天；未保存数据例外保留。历史表只保留小型汇总，读取和 CSV 导出离开 UI 线程，CSV 按日流式写入并原子替换。
- 面板退役后只请求一次空闲时优化 GC；没有循环强制回收或定期清空工作集。数据格式、实际键盘监听方式与保存周期保持兼容。

相关实现依据：Microsoft 的 [WPF 对象性能说明](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/optimizing-performance-object-behavior) 与 [共享冻结资源说明](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/freezable-objects-overview)。
